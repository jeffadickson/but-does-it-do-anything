Run actual C#: the IoC workbench

This workbench uses the collection's existing Roslyn/.NET WebAssembly worker. It compiles the editable source shown below, returning compiler diagnostics or standard output. No payment or network service is invoked by the examples.

Runtime requirements: Run through a local HTTP server or the built GitHub Pages site, not a double-clicked file:// URL. A modern browser needs WebAssembly, module workers and DecompressionStream. The worker loads about 21 MB of existing offline assets on first use. This runner does not include Microsoft.Extensions.DependencyInjection; the container examples in the main lesson require a local .NET SDK.

Run a preset or change the program.

What to change

In the direct-construction preset, the service creates its own gateway. In manual injection, construction moves into Main. In the swap preset, select two gateways without changing the checkout service. In the broken preset, fix the interface implementation and rerun to see Roslyn diagnostics disappear.

When switching presets, edits to each preset are preserved. Reset restores only the selected preset. Stop terminates the worker (it does not cooperatively cancel managed execution).
