# Inversion of Control: from early frameworks to modern .NET
Version 1.0.0 (2026-10-15). Historical analysis, progressive examples, six assessed exercises, injection and lifetime conceptual browser labs.
Open `app/index.html` directly (offline) or from repository root use `python tools/catalog.py check && python tools/catalog.py build && python tools/catalog.py serve`.
The web lesson executes JavaScript **simulations only**, not Spring or .NET; the C# code is intended for a local SDK with the `Microsoft.Extensions.DependencyInjection` NuGet package. Java samples require a Spring project and corresponding imports/setup.
Primary research links appear in the lesson's sources chapter. Outline/reviews: `OUTLINE_AND_REVIEWS.md`. Changelog: `CHANGELOG.md`. Issue: #7.
