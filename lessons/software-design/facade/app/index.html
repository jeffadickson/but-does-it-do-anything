WHEN DOES THE WRAPPER EARN ITS KEEP?

One changed rule.
How many edits?

Two test procedures configure a signal generator, wait for settling, read a meter, and turn the output off. Both work. Then a replacement instrument needs a longer settling time.

Conceptual simulation · no physical instruments connected

1. The straightforward version

Each procedure owns its instrument sequence. There is nothing inherently wrong with this when only one procedure needs it.

procedure A: configure → output on → settle 100 ms → read → output off
procedure B: configure → output on → settle 100 ms → read → output off

2. What changes?

The replacement instrument requires 300 ms of settling. Someone updates procedure A but misses B. Both still compile; B now reads too early.

3. Put the instrument sequence behind a facade

procedure A: station.measureResponse()
procedure B: station.measureResponse()

station: configure → output on → settle [one policy] → read → output off

Both callers use the same policy. A driver change or sequence change is localized to the station. A facade offers a simpler interface to collaborating subsystems; it can be a function or a class. The name does not make it useful.

4. Run the maintenance experiment

The model checks simulated settling durations; it does not actually wait. Both implementations use cleanup correctly. The comparison isolates duplicated policy, rather than pretending a facade is required for finally.
5. What did we gain—and pay?
Gain: one place to maintain the measurement sequence and a stable operation for callers. The missed update is visible in the experiment.
Cost: another API to design and maintain. A facade can become too broad or conceal controls advanced procedures need. Keep direct driver access available where appropriate.
Skip it: one small caller, no repeated subsystem coordination, and no expected variation. An ordinary helper may already provide all the value you need.
The remaining settling duration must come from actual instrument requirements and validation. This example’s 100/300 ms numbers are invented for teaching.
