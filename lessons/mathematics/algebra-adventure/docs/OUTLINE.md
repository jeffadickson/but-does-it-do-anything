# Algebra Adventure: revised teaching outline

Revision 2 — reviewed outline, 13 October 2026

This is a revised curriculum plan following an independent AI review from an elementary algebra teacher's perspective. It is not a review by a human teacher or evidence of classroom effectiveness. Implementation update — 13 October 2026: the standalone HTML now follows this 12-episode sequence, with revised labs, supported-practice tracking, preserved legacy progress, and matching 200-page color and monochrome coursebooks.

## Aim and pacing

For learners around nine: explain equality, find a missing number, justify an operation, substitute known values, and translate a simple total-and-difference story into equations. Preserve the parent's equality-first approach and early success with `2 + x = 3`.

Use short teaching episodes, roughly 10–15 minutes as a starting point, not twelve mandatory days. A learner who explains the equality checks can move directly toward simple solving. Pause or split an episode when needed. Quinn and Reagan can progress separately; do not compare their speed or treat age as readiness evidence.

Pictures, counters and equations are alternative ways to explain the same idea. Offer a picture when helpful; do not require a child to redraw a problem they can already explain symbolically. Keep a school bar model next to its matching equation. This is compatible in approach with part–whole and comparison pictures, without assuming any particular Singapore Math edition.

### A short entry conversation, not an exam

Ask the child to explain these without a timer:

- Is `5 = 3 + 2` true? Why? (Yes, both sides have value five.)
- `3 + 4 = □ + 5`: what belongs in the box? (Two; a response of seven suggests that equals is being read as “write the answer.”)
- Put out seven counters; hide three. How many can you see? (Four.)
- Before the equal-groups lesson only: share eight counters between two equal groups. (Four in each.)

Ask why an answer was chosen before inferring a misconception from a numeral alone. Allow counters and read text aloud. If arithmetic is the obstacle, use smaller numbers while keeping the algebraic structure. Do not require multiplication fluency before beginning equality and addition equations.

## Revised sequence

| Episode | One main idea and teaching example | Independent check and evidence to look for |
| --- | --- | --- |
| 1. Equals means same value | Compare `2 = 2`, `5 = 3 + 2`, `3 + 2 = 4 + 1`, and `3 + 2 = 6`. Evaluate each side separately; sort true/false. | Solve `3 + 4 = □ + 5` (2), then explain why `7 = 5 + 2` is true. Reads both sides as amounts, not a command followed by an answer. |
| 2. Change both sides | `10 = 10` → `10 − 2 = 10 − 2` → `8 = 8`. Add the same amount to both sides too. Try changing only one side, predict, and repair. | From `6 = 6`, subtract 1 on both sides (5 = 5). Explain why subtracting 1 on the left and 2 on the right breaks equality. Uses the same operation and amount. |
| 3. A letter names a number | Move from `□ = 3 + 2` to `x = 3 + 2`, then `x = 5`. Check by replacement. Informally find the box in `2 + □ = 3` before renaming it x. | `x = 4 + 2` (6), then test whether `x = 1` makes `2 + x = 3` true (yes). The letter is a number, not an object or multiplication sign. No second letter yet. |
| 4. Undo addition | `2 + x = 3` → `2 + x − 2 = 3 − 2` → `x = 1`. Also show `x + 2 = 3` and the reversed equation `3 = x + 2`. | Solve `x + 3 = 8` (5) and `2 + x = 2` (0); explain subtracting on both sides and check in the original. Zero is a valid answer. |
| 5. Undo subtraction | `x − 3 = 4` → `x − 3 + 3 = 4 + 3` → `x = 7`. Use a hidden starting amount from which three were removed. | Solve `x − 2 = 5` (7); choose addition rather than automatically subtracting the visible number. Check `7 − 2 = 5`. |
| 6. Equal groups and repeated unknowns | Two bags hold the same number of counters, eight altogether: `x + x = 8`, then `2 × x = 8`, then `2x = 8`. Divide both sides by two: `x = 4`. Explain why both bags use the same x. | Solve `3x = 12` (4) and explain what 3x means. Distinguish `2x` from `x + 2`, for example at x = 3 (6 versus 5). |
| 7. Replace a known value | `x = 3`; `B = 2 + x` → `B = 2 + 3` → `B = 5`. Every occurrence of x in this problem means three. Keep known x visibly separate from unknown B. | With `x = 4`, find `B = x + 3` (7). Identify x as known and B as the number to find. Optional discussion: `B = x + 3` alone does not give one unique pair. Try two pairs: (x,B) = (1,4) and (2,5). |
| 8. Undo two steps | Work with two bags holding equal numbers of counters, plus three loose counters: `2x + 3 = 11`. Remove three from both sides: `2x = 8`. Divide by two: `x = 4`. | Solve `2x + 5 = 13` (4), naming the operation and amount for each step and checking `2 × 4 + 5 = 13`. If the arithmetic is comfortable, vary the group count with `3x + 2 = 14` (4). This is required before the two-unknown room problem. |
| 9. Translate “more than” | A is the number of adults; C is the number of children. “Five more adults than children” means `A = C + 5`. Draw equal base bars plus an extra five. Try possible pairs before giving a total. | For “two more blue beads than red beads,” write `B = R + 2`. Test R = 3 (B = 5). Explain which is larger; identify the reversed relation `R = B + 2` as incorrect for this story. |
| 10. Two clues find two quantities | Room: `A = C + 5` and `A + C = 13`. Substitute: `(C + 5) + C = 13` → `2C + 5 = 13`. Use episode 8: C = 4, then A = 9. Match each term to the bar picture. | Four more blue beads than red, sixteen total: R = 6, B = 10. Show the two clues, obtain both counts, and verify both total (16) and difference (4). A table or diagram is a valid route; connect it to the equations. |
| 11. Choose a method and check | Mix familiar structures in short stories and symbols; do not tell the learner which operation to use. Revisit one previous idea at the start of the next session. | `x + 4 = 9` (5); `x − 4 = 3` (7); `2x = 10` (5); `2x + 1 = 9` (4). Explain one choice and correct “x + 3 = 8, so x = 11.” Use a fresh comparison story only if episodes 9–10 are secure. |
| 12. Optional answer detective | Five extra adults and twelve people: after removing the five extras, seven remain for two equal whole-number groups. That cannot work. Introduce C = 3.5 and A = 8.5 only if halves are familiar. | Four extra adults and twelve total is possible: C = 4, A = 8. Explain why one story works and the other does not. Fractions may describe lengths, but not whole-person counts here. This extension is not a completion gate. |

### Explicit pause points

Episode 6 has two phases: first represent repeated equal amounts and explain 2x; then share totals to solve. If 2x is not yet meaningful, stop before division and resume another session.

Episode 10 has two phases: solve with comparison bars and check both clues; then explicitly replace the whole A with (C + 5), matching every term to the picture. Either phase may take its own sitting. A correct bar solution counts as successful story reasoning even while expression substitution needs support. A learner who already reasons confidently with equations need not repeat a compulsory bar-solving routine.

## Worked bridge into the room problem

First solve the simpler two-step equation, without a second unknown or a story translation:

```text
2x + 3 = 11
2x + 3 − 3 = 11 − 3     subtract three from both sides
2x = 8
2x ÷ 2 = 8 ÷ 2          divide both sides by two
x = 4
Check: 2 × 4 + 3 = 11
```

Later, the room's two clues produce exactly this familiar type of equation:

```text
A = C + 5               A and C are counts, not names of people
A + C = 13
(C + 5) + C = 13        replace A with an equal expression
2C + 5 = 13             C + C is two copies of the same number
2C = 8                  subtract five from both sides
C = 4                   divide both sides by two
A = 4 + 5 = 9           return to the first clue
Checks: 9 + 4 = 13 and 9 − 4 = 5
```

In the comparison picture, one C-sized part represents all children and the matching part represents an equal number of adults. It does not mean that the room has two actual groups of children. Initially label both matching parts C or ?, not 4; uncover numerical labels after the learner solves.

## Teaching and feedback rules

1. **Make a prediction before a reveal.** Ask what the next step should accomplish. A worked example, a partly completed example, and then an independent example gradually remove support.
2. **Separate two kinds of change.** Adding five to both sides of `2 = 2` produces `2 + 5 = 2 + 5`. Reordering one sum as `5 + 2` is a separate property of addition. Never suggest the terms of subtraction can be freely swapped.
3. **Distinguish a legal move from a useful move.** Adding one to each side of `x + 2 = 5` preserves equality, but does not isolate x. Ask why subtracting two is efficient; do not mark every nonoptimal valid step mathematically wrong.
4. **Use the whole side.** Dividing `2x + 4 = 12` by two means `(2x + 4) ÷ 2 = 12 ÷ 2`, giving `x + 2 = 6`, not `x + 4 = 6`. This is an optional alternative-method example after episode 8, not its first explanation.
5. **Name an inverse operation, not “move and change sign.”** Avoid rules that hide the equality-preserving action.
6. **Ask for both evidence and an answer.** A drawing, pointing to counters, or an oral explanation counts; do not require fluent reading or formal prose.
7. **Keep restrictions honest.** When an activity permits only whole numbers or nonnegative intermediate terms, label that as the activity's scope, not as a universal rule of algebra. In subtraction equations, x − 3 must be available even though the written constant is negative.
8. **Do not front-load exceptions.** Division by zero is unavailable in the grouping activity. The reason zero cannot be a divisor and why multiplying by zero loses information belong in a grown-up note or later discussion, not the first unknown-number lesson.
9. **One stable value per problem.** Different letters can hold equal values; their names alone do not promise different numbers. A slider changing x should clearly start a new example. Do not animate x changing within one fixed equation as if every value remained a solution.

## Readiness without pressure

For each new idea, use a short fresh check: one familiar problem, one changed presentation, and an explanation or substitution check. Return to a previous idea at the next session. A supported answer means “practiced with help,” not “independently demonstrated.” If the child struggles, supply support and record the specific issue rather than labeling the child unsuccessful.

Suggested tracking is **explored / practiced with help / shown independently / revisited**. These are observations, not a validated assessment scale. Do not lock lessons or award mastery solely for a number of clicks, three correct answers, or time spent. Three similar generated questions can all be solved by following a surface pattern.

Before episode 10, look for interpretation of A = C + 5, substitution of a known number, reading C + C as 2C, and solving a fresh two-step equation. During episode 10, explicitly teach replacing a letter with an equal expression and checking both story clues. Those are learning targets, not entry requirements. Afterwards, look for those abilities with support gradually removed. If translation is the sticking point, keep the equation-solving skill and practice translating separately. Discussing multiple possible pairs in episode 7 is useful enrichment, not a gate to two-step solving. The total and difference clues determine the counts in these examples; do not generalize this into “any two equations always determine two unknowns.”

## Deliberately later

Unknown subtrahends such as `8 − x = 3`; equations with an unknown divisor; variables on both sides; negative solutions; fraction equations; general distribution; formal elimination of simultaneous equations. These are useful extensions, but they add new conceptual demands and are not prerequisites for the requested first course. Numerical division-as-sharing is introduced in episode 6; equations such as `x ÷ 2 = 4` can be a later inverse-operation extension rather than an extra requirement for the room problem.
