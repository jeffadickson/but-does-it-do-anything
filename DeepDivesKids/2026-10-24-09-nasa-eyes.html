Meet the idea

NASA Eyes is NASA's interactive visualization experience for exploring space missions and celestial objects.

Imagine this: visit the solar system from home. What would you make first?

How it works

It combines scientific data with 3D graphics so visitors can explore mission paths and planetary scenes.

Try predicting: What changes when you give the program a different instruction or number?

Try it!

This standalone JavaScript estimates distance for a pretend probe moving at constant speed.

const speedKmPerSecond = 12;
const timeSeconds = 60;
const distanceKm = speedKmPerSecond * timeSeconds;
console.log('Distance: ' + distanceKm + ' km');

What makes it tricky?

Visualizations simplify some details and are not substitutes for mission navigation or engineering analysis.

Can we use it?

NASA Eyes is a NASA product, not a general-purpose JavaScript library; NASA media/software reuse has specific terms. Do not infer an open-source license.

Ask an adult before installing software, publishing creations, or sharing personal information.
