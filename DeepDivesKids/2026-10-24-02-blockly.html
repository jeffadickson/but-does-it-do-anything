Meet the idea

Blockly lets programmers snap together blocks of instructions, like a jigsaw puzzle.

Imagine this: make a robot follow instructions. What would you make first?

How it works

Blocks represent statements or values and can generate code in programming languages; the editor prevents many syntax mistakes.

Try predicting: What changes when you give the program a different instruction or number?

Real examples—not guesses

Google's official Blockly demos and developer guides demonstrate block-based editors and code generation.

Our invention challenge

A pretend RISCue robot could use blocks for turn, move, and repeat; this is an idea to build, not an existing project feature.

A possible connection to Dad's work is testing ideas one step at a time, as engineers do with simulations, code, and careful experiments.

Try it!

Try this JavaScript version of the blocks: the loop repeats exactly three times.

for (let step = 1; step <= 3; step++) {
  console.log('Robot moves: ' + step);
}

What makes it tricky?

Blocks make logic friendly but very large programs can be clumsy to arrange.

Can we use it?

Blockly is Apache-2.0 licensed. A full drag-and-drop editor requires integrating the Blockly JavaScript package.

Ask an adult before installing software, publishing creations, or sharing personal information.
