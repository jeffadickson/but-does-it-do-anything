Meet the idea

Three.js helps draw 3D worlds in a web browser.

Imagine this: build a tiny 3d planet. What would you make first?

How it works

It uses a scene, camera and renderer; objects have geometry and materials, and a render loop displays them.

Try predicting: What changes when you give the program a different instruction or number?

Real examples—not guesses

The Three.js manual's Creating a Scene tutorial builds a rotating 3D cube.

That's a documented example from the project's own published material. It does not establish that the software powers NASA missions, professional games, or Dad's projects.

Our invention challenge

You could build a planet tour inspired by spacecraft missions; that is a possible student project, not a documented NASA implementation.

Try it!

Read this pseudocode plan, then try the official tutorial to build the real scene.

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, 2, 0.1, 100);
const planet = new THREE.Mesh(
  new THREE.SphereGeometry(1, 24, 16),
  new THREE.MeshNormalMaterial()
);
scene.add(planet);
// Add a WebGLRenderer and animation loop
// as shown in the official tutorial.

What makes it tricky?

Great interactive 3D, but needs GPU/browser support and understanding of cameras, lighting, and frames.

Can we use it?

Three.js is MIT licensed. The snippet needs Three.js loaded and a renderer added; it is instructional, not a standalone complete sketch.

Ask an adult before installing software, publishing creations, or sharing personal information.
