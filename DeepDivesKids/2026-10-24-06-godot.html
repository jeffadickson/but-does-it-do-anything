Meet the idea

Godot is a free, open-source game engine for making 2D and 3D games.

Imagine this: make a character move in a game. What would you make first?

How it works

A scene holds nodes such as characters and sprites; scripts react to input and update game objects.

Try predicting: What changes when you give the program a different instruction or number?

Try it!

Put this GDScript on a CharacterBody2D node in Godot 4, then set up input actions.

extends CharacterBody2D

@export var speed: float = 250.0

func _physics_process(delta: float) -> void:
    var direction := Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
    velocity = direction * speed
    move_and_slide()
