01 / Story

The one-second mystery

Imagine a puck coming straight at the net. First your eyes see it. Next your brain decides where to move. Then your hands or feet act. Even a lightning-fast goalie needs some time for that chain.

Today you can measure some of that time in milliseconds. One millisecond (ms) is one-thousandth of a second.

Your prediction: Will you react sooner when you know roughly when the puck will come? Or does the surprise make you more alert? Predict, then test.

👀 → 🧠 → 🧤

Notice: Spot the puck.
Decide: Pick a lane.
Act: Press the matching key.

Being fast but choosing the wrong lane is still a miss. That's why our lab measures both speed and accuracy.

This original three-choice game is not a validated medical or hockey-skills assessment.

⏱ 1 second = 1,000 ms

Suppose you take 300 ms to respond. That's 0.3 seconds. Fast, but not zero! The game's clock counts the time between its code showing the puck and receiving your input.

📊 Why the median?

Sort your five times from fastest to slowest. The median is the middle number. Unlike an average, one unusually slow shot cannot pull it as far away. We show times for both saves and misses.

Important: Screen refresh, browsers, touchscreens and keyboards add delays. Choice between three lanes also adds thinking. These scores aren't a diagnosis or proof of anyone's hockey ability.

04 / Hands-on, no screen required

A ruler can become a stopwatch

Find a light, 30 cm ruler and a partner. Your partner holds it straight up, with its zero mark level with your open thumb and first finger. Without telling you when, they let go without pushing.

  1. Catch it by pinching your fingers together.
  2. Read the centimeter mark where you caught it.
  3. Try five times; switch jobs.
  4. Use the slider to discover its approximate falling time.

The farther it falls, the more time gravity had to speed it up. A ruler is a fun experiment but uses different movements from the computer game, so the times shouldn't match exactly.

Safety: use a lightweight ruler near a clear table, away from faces. Never use sharp, heavy or breakable objects.

📏 Drop-distance calculator

192 ms

Model: an object dropped from rest on Earth, ignoring air resistance.

Time = √(2 × distance in meters ÷ 9.81). At 18 cm: about 0.192 seconds.

05 / Try the code

How does a computer measure a moment?

The browser has a tool called performance.now(). It reports elapsed milliseconds from a clock designed to keep moving forward even if a computer's wall clock changes. That's useful in engineering, where the order and timing of events matter.

const first = performance.now();
// An event happens later...
const second = performance.now();
const elapsedMilliseconds = second - first;
console.log(Math.round(elapsedMilliseconds));

The game uses built-in HTML, CSS and JavaScript. No extra library, login, package download or remote server is required. It uses a random time delay and compares the chosen lane with the real one. You could save the file and play it offline.

🔩 Dad's RISCue project

A button press is an event. So is a sensor measurement. An RTOS helps software decide when work should happen. Our lesson is only a friendly analogy — it is not evidence that RISCue uses this game.

🛰 Dad's VeloSim project

Engineers simulate events to explore what systems do. You can record your five times and try the experiment again. But unlike a fully deterministic simulation, this game has random waits and human responses.

Precision trap: Our timestamp is captured when the code changes the puck's appearance, before the screen necessarily paints it. The monitor and input hardware can add unmeasured delay. A fine-grained clock is not a perfectly calibrated laboratory.

06 / Research detective

What really exists? What is just an idea?

Verified real use

🚀 NASA reaction tests aboard ISS

NASA's Psychomotor Vigilance Test (PVT), called the Reaction Self Test on the International Space Station, has been used to study astronaut attention and fatigue. NASA's project record describes a study of 24 astronauts on long missions. Their standardized visual-signal test is different from our three-choice game.

Build, license, safety and privacy

Integration: one self-contained HTML file; no dependencies, external scripts, fonts, images or registration. Open it in a modern browser with JavaScript enabled. Text and sources remain readable without scripts.

Technical limits: cue timestamp is recorded before physical display. Timers can be delayed, and key/touch response adds device latency. Hidden-tab play stops. It measures five three-choice responses, not standardized PVT and not hockey performance.

Accessibility: semantic sections, keyboard or touch controls, focus indicators, a text-based live status, labelled controls and a no-screen ruler alternative. No flashing or audio is needed; reduced-motion preferences are respected.
