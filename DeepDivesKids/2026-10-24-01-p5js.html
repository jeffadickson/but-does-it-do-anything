Meet the idea

p5.js is a JavaScript library for drawings, animations, and creative coding.

Imagine this: draw a hockey puck that moves. What would you make first?

How it works

A program creates a canvas; setup() runs once, then draw() repeats to animate a scene.

Try predicting: What changes when you give the program a different instruction or number?

Real examples—not guesses

The official p5.js reference demonstrates drawing circles and continuous sketches.

That's a documented example from the project's own published material. It does not establish that the software powers NASA missions, professional games, or Dad's projects.

Try it!

Paste this in editor.p5js.org. Move your mouse: the puck follows it.

function setup() {
  createCanvas(420, 240);
}
function draw() {
  background(211, 231, 250);
  fill(20, 40, 75);
  circle(mouseX, mouseY, 32);
}

Challenge: Change one number or direction, predict the result, and record what happened. If this is pseudocode or a partial library example, use the linked official environment or tutorial.

What makes it tricky?

Easy to begin and expressive; browser animation is not a high-precision physics simulator.
