The big idea

Computers start with tiny yes-or-no questions.

Imagine a pretend hockey arena. A sensor says, “The puck crossed my line!” A human scorer says, “Count it!” Our little machine turns on a goal lamp only when both agree.

⚫ 0 means OFF

Like a light switch that is down, or a question answered “no.”

🟡 1 means ON

Like a light switch that is up, or a question answered “yes.”

🧠 A gate makes a rule

It takes in bits (0s and 1s) and produces a new bit.

Mission: Learn three gates, build a pretend goal light, and make a 3-bit counter that counts from zero to seven. No actual rink sensors required.

Chapter 1 · How it works

Three little rules that make big things

AND — “Both!”

The lamp shines only if A and B are both 1. Example: sensor AND approval.

OR — “Either!”

The lamp shines if A or B or both are 1. Example: either alarm switch is on.

XOR — “Different!”

The lamp shines if exactly one input is 1. When both match, it's off.

Surprise: XOR is also a tiny piece of addition! It produces the last digit of 1 + 1, which is 0 in binary. AND produces the carry bit, which is 1. Put the carry in front and you get 10 (two in binary).

A truth table is a complete answer sheet for a gate. With two on/off inputs, there are exactly four combinations: 00, 01, 10, and 11. We can check every one!

Add up the places whose bits are 1. Example: 101 means 4 + 0 + 1 = 5.

Inside the counter: The rightmost bit uses XOR to flip. AND passes a carry to the next bit only when the old bit was already 1. This is a real digital-addition idea, shown here in JavaScript.
Limit: Three bits hold only eight values (0–7). The next count wraps back to 0, so our toy scoreboard announces “overflow!” A real game scoreboard needs more bits, proper sensors, controls, and official scoring decisions.

Chapter 5 · Away from the screen

✂️ Make a paper logic computer

You'll need paper, a pencil, and two coins or two scraps labeled 0 and 1. No batteries!

  1. Draw a table with columns A, B, AND, OR, XOR. Write the four A/B pairs: 00, 01, 10, 11.
  2. Predict the answers. Try using “both,” “either,” and “exactly one” instead of memorizing.
  3. Flip two coins to pick A and B. Ask a partner to calculate the output. Check the screen's truth table.
  4. Challenge: Make a pretend goal light out of a paper circle. One person plays the puck sensor, another plays the scorer. Light the paper lamp only when both say YES.
Try this with a teammate: can you invent a situation where XOR is better than OR? Hint: what if two switches should not be on together?

Chapter 6 · Working code

💻 Write a tiny computer in JavaScript

This code uses built-in JavaScript operators: & for AND and ^ for XOR. You don't have to install a library. Try it in a browser console or a .js file.

// A and B must each be 0 or 1.
function andGate(a, b) {
  return a & b;
}
function xorGate(a, b) {
  return a ^ b;
}
// Add one to a 3-bit number (0 through 7).
function addOne3(score) {
  let carry = 1;
  let result = 0;
  for (let bit = 0; bit < 3; bit++) {
    const oldBit = (score >> bit) & 1;
    const newBit = xorGate(oldBit, carry);
    carry = andGate(oldBit, carry);
    result |= newBit << bit;
  }
  return { value: result, overflow: carry === 1 };
}
console.log(addOne3(4)); // { value: 5, overflow: false }
console.log(addOne3(7)); // { value: 0, overflow: true }

Experiment: What happens when you change bit < 3 to bit < 4? Explain why you also need to change the display to show a fourth bit.

Chapter 7 · Fact check

🌍 What is real? What did we invent?

Documented Real gate chips

Texas Instruments documents the SN74HC08 as a chip containing four two-input AND gates and the SN74HC86 as a chip containing four two-input XOR gates. Those are manufactured electronic parts, not just a screen trick. Sources 1–2.

Documented A real FPGA board

Sipeed documents the Tang Primer 20K with 20,736 four-input lookup-table logic units and a tutorial for blinking a real LED using the board. Its FPGA can be configured to implement logic circuits. Sources 3–4.

Our invention Hockey goal machine

Our pretend sensor, approval button, quiz, and 3-bit scoreboard are learning games. We have not shown that a real hockey rink uses these exact rules or components.

The FPGA doesn't simply contain 20,736 physical AND gates. Its configurable lookup tables can represent many different small logic functions. Also, a browser simulation does not program a real circuit board.

Connection to engineering: Before building real hardware, engineers make small models and test every possible input. This page does the same for two-input gates: only four input combinations, so we can test all four. That resembles the repeatable testing ideas behind your dad's SharpHDL and simulation projects—on a much smaller scale.

Chapter 8 · Truthful engineering

⚖️ Cool powers, honest limits, and licensing

✅ What's great?

Gates are simple, predictable, and easy to test. Put enough together and you can add numbers, choose actions, and build controllers.

⚠️ What gets tricky?

Real circuits have electricity, timing, wires, heat, and sometimes unexpected signals. They need careful design and testing—not just correct truth tables.
