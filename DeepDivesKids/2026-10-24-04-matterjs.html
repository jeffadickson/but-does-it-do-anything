Meet the idea

Matter.js is a 2D physics engine that simulates moving and colliding objects.

Imagine this: what happens when things collide?. What would you make first?

How it works

It updates bodies step by step, combining gravity, contact detection, and collision responses.

Try predicting: What changes when you give the program a different instruction or number?

Real examples—not guesses

The official Matter.js examples include stacked bodies and collision demonstrations.

That's a documented example from the project's own published material. It does not establish that the software powers NASA missions, professional games, or Dad's projects.

Make a toy hockey puck bounce off boards to explore movement; the engine is not a certified real-world puck model.

Try it!

Paste into a project with Matter.js loaded to make one simple falling ball.

const engine = Matter.Engine.create();
const ball = Matter.Bodies.circle(100, 40, 18);
const floor = Matter.Bodies.rectangle(200, 220, 400, 30, {
  isStatic: true
});
Matter.Composite.add(engine.world, [ball, floor]);
Matter.Engine.update(engine, 1000 / 60);
console.log(ball.position.y);

Challenge: Change one number or direction, predict the result, and record what happened. If this is pseudocode or a partial library example, use the linked official environment or tutorial.

What makes it tricky?

Fun for approximate interactive physics; real materials, exact contacts, and deterministic cross-platform behavior need special care.

Can we use it?

Matter.js is MIT licensed. This example uses its JavaScript API and needs the Matter.js library loaded.
