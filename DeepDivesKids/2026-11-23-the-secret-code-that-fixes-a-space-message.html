📨 The message mystery

Imagine you are tracking a robot a very long way from Earth. It sends four tiny facts: 1, 0, 1, 1. But the radio signal has a noisy journey. One bit (a zero or one) arrives the wrong way round. How can we catch it?

🔢

Step 1: Message

A bit is either 0 or 1. Computers build pictures, commands and measurements from lots of bits.

🌪️

Step 2: Noise

A signal or stored bit can change. We call a 0 becoming 1—or a 1 becoming 0—a bit flip.

🛠️

Step 3: Rescue

Add clever check bits before sending. The receiver uses them to find and repair a single mistake.

Key discovery: the check bits do not magically know the answer. Their overlapping clues tell us where one mistake happened.

🕵️ Three secret detectives

We'll learn Hamming(7,4): start with 4 message bits, add 3 check bits, and send 7 bits. This is a small, genuine error-correcting code, described in university engineering materials. Our detectives guard overlapping groups of positions.

Each detector counts the 1s in its group. An even count means “pass.”
DetectivePositions watchedSecret question
🟦 P11, 3, 5, 7Is the number of 1s even?
🟪 P22, 3, 6, 7Is the number of 1s even?
🟧 P44, 5, 6, 7Is the number of 1s even?

The four real data bits live in positions 3, 5, 6 and 7. The detectives' own check bits live in positions 1, 2 and 4. We choose those check bits so every detector starts with an even number of 1s.

After the trip, the receiver checks again. Suppose detectives P1 and P4 shout “wrong!” but P2 says “fine.” Add their detective numbers: 1 + 4 = 5. Under the one-bit mistake rule, bit 5 is the culprit!

Super important: Hamming(7,4) can correct one bit flip. It cannot safely tell one flip from two flips: a pair can trick the decoder into changing a third bit. We will purposely test that failure.

🌍 Three real-world clues from the inventors and engineers

🚀

Voyager spoke through noise

Documented fact: NASA/JPL reports that the two Voyager spacecraft were the first spacecraft to use Reed–Solomon error correction, helping increase their data rate. That is a different, more powerful family of codes—not our tiny Hamming(7,4) toy.

Read the JPL Voyager story.

📡

Deep Space Network listens

Documented fact: JPL's March 11, 2025 telemetry handbook says nearly all spacecraft use forward error correction for telemetry and lists convolutional, Reed–Solomon, turbo and LDPC decoding support.

Explore JPL's actual engineering handbook (PDF).

💾

Computer memory gets protection

Documented fact: AMD's UltraScale UltraRAM documentation describes optional Hamming-based ECC: 64 data bits and 8 protection bits, correcting a single error or detecting a double error.

See AMD's hardware documentation.

✅ What evidence supports

Error-control codes are genuine space-communication and computer-memory techniques. Hamming(7,4) is a working classroom example of one-error correction. The linked organizations explicitly document their real, typically larger codes.

💭 What we're imagining

Our playful spacecraft sending four tiny bits is make-believe. We are not claiming Voyager or today's deep-space missions use this exact seven-bit demonstration. Our “space rescue” is a simplified teaching game.

✂️ Build your own paper error-correcting machine

What you need

Seven small paper squares, a pencil, three colored crayons and a partner. Write big numbers 1 through 7 on the squares. You can also use seven coins showing heads (1) or tails (0).

Time: about 10–15 minutes. Nothing sharp or electrical is required.

Mission rules

Start with data bits 1, 0, 1, 1, placed at squares 3, 5, 6, 7. Fill squares 1, 2 and 4 with whatever 0 or 1 makes each detective's group even. You should find the same transmitted bits as the computer lab.

  1. Encode: draw three colored circles around the watched squares listed in the detective table. Add the 1s in each circle. Choose each check bit so that circle's total is even.
  2. Sabotage: the partner secretly changes just one square from 0 to 1, or from 1 to 0.
  3. Investigate: check the three circles. Add the numbers of failed detectives (1, 2 and/or 4). That sum points to the changed square.
  4. Repair: flip that square back. Then try two secret changes. Did the detective trick still work?
Try this: if you flip square 6, detectives P2 and P4 should both complain. Their numbers add up to 6.

🏒 The bigger engineering playbook

🥅

Hockey teamwork

Imagine a goalie and defenders watching overlapping lanes. One teammate alone might only know that something went wrong. Different overlapping observations can help locate the trouble. That's an analogy, not actual hockey error-correcting code.

🔧

Dad's hardware experiments

In projects like TinyTMR and SharpHDL, engineers care about detecting mistakes and making hardware reliable. Triple modular redundancy checks three copies with a vote; Hamming code adds check bits. They're different strategies for handling faults.

🛰️

Spacecraft care about trust

Mission systems need to know whether data can be trusted. Your lab shows why adding bits is useful, and also why engineers must test failures beyond the easy one-bit case.

⚖️ The engineering tradeoffs

Automatically repairs any single flipped bit in a seven-bit word.It sends 7 bits to protect only 4 data bits: 3 extra bits (75% overhead relative to the four data bits).

For older explorers: adding an eighth overall parity bit gives an extended Hamming code that can usually be described as “correct one, detect two” under its assumed error model. Our seven-bit game intentionally has no such extra protection.

💻 Tiny peek at the code

Here is the real idea used inside the interactive lesson: XOR (^) is 1 when two bits are different. Tally all watched bits with XOR to see whether a group has odd parity.

function parity(bits, mask) {
  let odd = 0;
  for (let position = 1; position <= 7; position++) {
    if (position & mask) odd ^= bits[position - 1];
  }
  return odd; // 0 = even, 1 = odd
}

🧠 Mini challenge: Can you catch it?

Question 1: P1 and P2 complain, P4 is happy. Which bit is wrong, assuming one flip?

Answer: bit 3, because 1 + 2 = 3.

Question 2: Two bits changed. Can the seven-bit Hamming decoder promise the right answer?

Answer: no! It can be tricked. Try the pink two-flip button and inspect the sender's secret comparison.

Question 3: Is Hamming(7,4) the same error-control code as Voyager's?

Answer: no. JPL documents Reed–Solomon for Voyager. Our smaller Hamming code is a real mathematical teaching example.
