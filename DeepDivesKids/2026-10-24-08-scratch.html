Meet the idea

Scratch is a visual programming environment where colorful blocks make characters and animations do things.

Imagine this: invent a game with talking sprites. What would you make first?

How it works

Sprites each own scripts that respond to events; events can start motion, sound, stories, and games.

Try predicting: What changes when you give the program a different instruction or number?

Real examples—not guesses

Scratch's official Ideas page and tutorials teach starter projects such as games and animation.

That's a documented example from the project's own published material. It does not establish that the software powers NASA missions, professional games, or Dad's projects.

Our invention challenge

Make a two-player puck race or a story about a robot exploring the Moon; these are suggested creations.

A possible connection to Dad's work is testing ideas one step at a time, as engineers do with simulations, code, and careful experiments.

Try it!

Here is plain-language pseudocode that matches a Scratch-style script; build it using blocks.

when green flag clicked
set score to 0
repeat 10
  move 10 steps
  if touching edge then
    turn 15 degrees
  end
end

Challenge: Change one number or direction, predict the result, and record what happened. If this is pseudocode or a partial library example, use the linked official environment or tutorial.

What makes it tricky?

Very accessible, but code must be recreated using Scratch blocks. Some projects are limited by available editor features.

Can we use it?

Scratch source code, editor assets and community shared projects can have different licenses; check official terms before republishing others' artwork or projects.

Ask an adult before installing software, publishing creations, or sharing personal information.
