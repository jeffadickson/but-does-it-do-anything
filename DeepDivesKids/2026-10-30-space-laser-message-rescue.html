Mission briefing · 01

How do you mail a message across space?

A spaceship cannot toss a paper letter toward Earth. Instead, it sends information as signals.

Your computer represents information using just two numbers: 0 and 1. Each one is a bit. Bits can describe letters, pictures, music, or even hockey scores. A spacecraft can send bits by changing a radio or light signal over time.

📫 A letter

Imagine the spacecraft wants to tell Earth: R for Reagan. We turn the letter into a pattern of seven bits.

🧩 A mystery

What if one bit changes on the trip? The receiver might read the wrong letter. How could it notice?

Think of a goalie hearing the coach shout "LEFT!" across a noisy rink. The message is useful only if it arrives correctly.

Build the idea · 02

Seven bits + one superhero check bit

In our toy system, the letter R is number 82 in the ASCII alphabet chart. In seven binary digits, 82 is 1010010. The 1s are the "on" positions. Count them: there are three.

We add an eighth bit called a parity bit. Our rule is easy: the total number of 1s in all eight positions must be even. Three is odd, so we add a 1. Now there are four 1s. That is even.

Original packet

1 0 1 0 0 1 0 | 1

The final golden bit is the check bit. Count all the 1s: 4. Check passed!

After one accident

1 0 1 0 0 0 0 | 1

A single bit changed, so only 3 ones remain. The receiver can detect trouble.

Important: Parity is an error detector. It warns that something may be wrong. It does not tell you which bit changed or how to repair it.

Here's the twist: if two bits change, the number of 1s can still be even. That is why real communications systems need much more powerful techniques.

True space history · 03

NASA really sent data using laser light!

NASA's Deep Space Optical Communications (DSOC) experiment flew with the Psyche spacecraft. Engineers at NASA's Jet Propulsion Laboratory built a way to send and receive data using carefully aimed near-infrared laser light, which human eyes cannot see. The experiment was about future ways to move information faster from very far away. Sources 1–3.

📅 December 11, 2023

DSOC transmitted a short ultra-high-definition video from about 19 million miles (31 million kilometers) away, at up to 267 megabits per second. That is real NASA test history. Source 1.

📅 September 2, 2025

DSOC finished its 65th and final communication pass. NASA said the demonstration had exceeded its technical goals. It was a completed experiment, not a service for sending ordinary messages to Mars. Sources 1–2.

DOCUMENTED Laser-based deep-space data transmission is real. JPL reports that DSOC demonstrated data rates at least 10 times higher than comparable state-of-the-art radio systems.
OUR IMAGINATION Our classroom spaceship sends a single ASCII letter with one even-parity check bit. NASA did not report using this little classroom packet format for DSOC. Our game is an analogy about data errors, not a model of DSOC's actual laser modulation or error-correction system.

Offline invention · 05

Try it with paper: a message from Planet Hockey

You do not need a computer for this experiment. Get eight small pieces of paper and a pencil. No lasers, bright flashing lights, or batteries are needed.

Build. Write the packet 1 0 1 0 0 1 0 1, one digit per paper square. Place a star above the last square: it is the check bit.
Transmit. One explorer looks away. The other secretly flips exactly one paper square from 1 to 0 or 0 to 1.
Inspect. Count the 1s. If the total is odd, announce "ERROR DETECTED!" You do not know which square changed.
Level up. Reset, then secretly flip two squares. Count again. Why did the alarm stay quiet?

Optional family challenge: Ask one person to be Mission Control, one to be the spacecraft, and one to be the mischievous cosmic gremlin. Swap roles!

For curious coders · 06

A real JavaScript mini-program

This is a small version of the algorithm running in the lab above. It uses normal browser JavaScript: no library download, cloud account, or build tools. The charCodeAt operation converts a one-letter string into a number. See MDN Source 4.

// Send one uppercase ASCII letter, like R.
function encodeLetter(letter) {
  const number = letter.charCodeAt(0); // R → 82
  const data = number.toString(2)
    .padStart(7, "0")
    .split("")
    .map(Number);
  const ones = data.reduce((a, b) => a + b, 0);
  const checkBit = ones % 2; // Makes the total even
  return [...data, checkBit];
}

// A receiver checks all eight bits.
function parityIsEven(packet) {
  const ones = packet.reduce((a, b) => a + b, 0);
  return ones % 2 === 0;
}

const sent = encodeLetter("R");
const received = [...sent];
received[5] ^= 1; // Flip one data bit
console.log(sent.join("")); // 10100101
console.log(parityIsEven(received)); // false
👩‍🚀 How can I change the code?

Change "R" to "Q". Then try changing received[5] to received[7] to flip the parity bit instead. Or flip two positions and predict the result. This simplified seven-bit encoding is limited to basic ASCII (letters A–Z here).

Connect the dots · 07

How this connects to your world

🏒 Hockey

Reagan as goalie and Quinn as skater both need accurate information. A shouted instruction that changes from "LEFT" to "RIGHT" is a communication error. Counting bits is one way computers look for trouble.

🎨 Art + science

The real DSOC experiment sent a video and test data, not just numbers for fun. That means beautiful images and scientific results can travel as bits through a signal.

🛠️ Dad's engineering

Projects such as RISCue (a tiny computer design) and TinyTMR (circuits built to keep working when parts misbehave) ask an important question: How do we spot or survive mistakes? This parity game is a first step, not flight-ready technology.

🌲 Nature

A hike can be a message hunt: invent an eight-symbol code with sticks and stones, then let wind or a teammate alter one symbol. Which clues tell you that the message may have changed?

Suggested, not verified: A homemade family rover or a future classroom game could use similar checks to spot wrong button commands. This is an idea for a project; we are not claiming that RISCue or any real spacecraft uses this exact toy parity scheme.
A real engineer asks "what's missing?" · 08

What our model gets right — and what it doesn't

✅ Good for learning

  • Bits represent information.
  • One even-parity check bit detects any odd number of flipped bits in our eight-bit packet.
  • Two flipped bits can fool it.
  • Everything works in a browser without network access.

⚠️ Not a real deep-space link

  • We ignore faint light, pointing errors, timing, weather, and noise statistics.
  • Parity detects errors; it does not repair them.
  • Our 7-bit ASCII examples are not NASA DSOC's format.
  • Two or any even number of flips can escape this parity test, even if the data is wrong.

Why not use fancy library software? Because this is a tiny eight-bit game. Plain JavaScript lets you inspect every step and keeps the whole page self-contained. Real mission systems use far more sophisticated designs, and engineers test them under realistic conditions.
