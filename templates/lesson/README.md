# Lesson development

Fill in lesson.json and app/index.html before committing. Add examples/, tests/, tutorial/, and assets/ only as needed. Only app/ is copied into the published site. Downloadable files must be copied into app/downloads/ by the lesson's documented build step.

Document: prerequisites, run/build/check commands, actual execution mode, external dependencies, source provenance, verification performed, and known limitations. Use the problem → straightforward solution → pressure → improved design → experiment → payoff/cost sequence.
